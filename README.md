# WordLock for iPhone (초기 iOS 앱)

## 현재 범위

- SwiftUI 기반의 오프라인 학습 앱입니다. 계정이나 서버 동기화 없이 단어, 암기 상태, 오답과 학습 기록을 이 기기에 저장합니다.
- Android의 기본 7개 단어장 6,200개를 함께 담습니다: 초등 800, 중등 기본 800, 중등 고난도 1,800, 고등 기본 1,000, 고등 고난도 500, 고등 최상위 300, 회화 1,000.
- 단어장 선택, 4지선다/철자 퀴즈, 목표 정답 수, 건너뛰기, 오답 복습, 나만의 단어장/단어 추가·이름 변경, 다크 모드를 우선 구현합니다.

## iPhone의 잠금 관련 제한

iOS 앱은 Android 접근성 서비스처럼 잠금 해제 전 앱을 자동 실행하거나, 사용자가 다른 앱으로 나가는 것을 보편적으로 막을 수 없습니다. Apple Screen Time API는 Family Controls 권한과 배포 entitlement 승인이 있어야 하며 선택한 앱에 시스템 차원의 가림막을 적용하는 제한된 기능입니다. 이 초기 빌드는 그 권한을 요청하지 않으며, 잠금화면 퀴즈나 기기 전체 강제 잠금을 약속하지 않습니다.

## 빌드

`LockWord.xcodeproj`를 macOS의 Xcode에서 열고 개인 개발팀을 선택해 iPhone에 설치할 수 있습니다. 현재 작성 환경은 Windows이며 Xcode/iOS Simulator가 없어 여기서 서명, 시뮬레이션, iPhone 설치 또는 App Store 제출은 할 수 없습니다. 빌드와 화면 흐름은 macOS에서 확인한 뒤 배포해야 합니다.

## 데이터 출처

`Resources/built_in_words.csv`는 Android 앱의 기존 오프라인 기본 단어 자료를 그대로 재사용합니다. CSV의 빈 영어/뜻, 각 단어장 안의 중복 표기는 원본을 대상으로 확인했습니다. 모든 번역의 사전적 정확성을 새로 보증한다는 의미는 아닙니다.
